## Priority Issues (P0–P3)

### [P1] Desktop Viewport Lockout in ManagementHubPage
- **What**: Hard redirect on `window.innerWidth >= 1024` forces desktop users back to `/dashboard`.
- **Why it matters**: Desktop and tablet operators are blocked from viewing the administrative command hub.
- **Fix**: Remove the hard redirect and render a desktop administrative grid.
- **Suggested command**: `$impeccable adapt fontend/src/pages/ManagementHubPage.tsx`

### [P1] The "Now What?" Void: Lack of Emergency Action in Critical Flood Alarm
- **What**: When water breaches critical level, the alert banner only offers a view switch (`ดูจุดวิกฤต`) with no emergency dispatch mechanism.
- **Why it matters**: Delays emergency response; operators cannot broadcast push notifications to LINE subscribers from the alarm state.
- **Fix**: Add a contextual "ยิงแจ้งเตือนด่วน LINE OA" button with confirmation modal inside the critical banner.
- **Suggested command**: `$impeccable shape alert-dispatch`

### [P2] Cognitive Overload in 8-Card Bento Sensor Grid
- **What**: `StationTelemetryHub.tsx` dumps 8 flat diagnostic metrics simultaneously.
- **Why it matters**: Violates working memory limits ($\le 4$ items); forces operators to sift through environmental vs hardware data.
- **Fix**: Chunk into two sub-groups: "สุขภาพอุปกรณ์และพลังงาน" (Battery, Voltage, Tilt) and "เครือข่ายและสภาพอากาศ" (RSSI, SNR, Gateway, Temp, Humidity).
- **Suggested command**: `$impeccable layout fontend/src/components/dashboard/StationTelemetryHub.tsx`

### [P2] Zero Keyboard Accelerators for Field & EOC Operators
- **What**: No keyboard navigation for station cycling or core functions.
- **Why it matters**: Slows down emergency operations.
- **Fix**: Add global keyboard shortcuts (`1`-`9`, `[` / `]`, `R` refresh, `M` map toggle).
- **Suggested command**: `$impeccable polish fontend/src/pages/DashboardPage.tsx`

### [P3] Lack of Citizen Context for Negative Elevation & Sensor Jargon
- **What**: Negative values (`-0.45 ม.`) and abbreviations (`RSSI`, `SNR`) lack micro-tooltips.
- **Why it matters**: Citizens get confused by negative water numbers, misinterpreting safe states as errors.
- **Fix**: Add micro-tooltips explaining that negative values represent water safely below the embankment.
- **Suggested command**: `$impeccable clarify fontend/src/components/dashboard/StationTelemetryHub.tsx`
